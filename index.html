🌐 Wi-Fi & DNS

Situs web tidak dapat mengubah DNS Wi-Fi iPhone secara langsung. Untuk mengatur DNS secara manual, lakukan dari Settings iPhone:

  1. Buka Settings → Wi-Fi.
  2. Ketuk tombol info (ⓘ) di samping jaringan yang sedang tersambung.
  3. Pilih Configure DNS → Manual.
  4. Tambahkan alamat DNS dari penyedia yang kamu percaya, lalu simpan. Catat konfigurasi lama sebelum mengubahnya.
Bantuan Apple

DNS tidak membuat portal ini terbuka otomatis dan tidak menghapus Activation Lock. Hindari profil konfigurasi yang tidak kamu percayai.

⌂ Tambahkan ke Home Screen

Website tidak dapat memaksa iPhone keluar ke Home Screen atau mengubah Home Screen sistem. Kamu bisa memasang pintasan portal secara manual:

  1. Buka situs ini di Safari.
  2. Tekan tombol Share (kotak dengan panah ke atas).
  3. Pilih Add to Home Screen / Tambahkan ke Layar Utama.
  4. Tekan Add. Ikonnya akan tampil seperti pintasan aplikasi.

Jika pilihan tidak terlihat, gulir menu Share atau pastikan kamu menggunakan Safari.
